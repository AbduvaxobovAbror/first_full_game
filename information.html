🧠 Overview

This is a browser-based 2D endless runner game built using HTML, CSS, and JavaScript. The main goal is to survive as long as possible by jumping over obstacles and achieving the highest score.

The game demonstrates key programming concepts such as:

  • DOM manipulation
  • Event handling (keyboard input)
  • Collision detection
  • Game loop logic
  • Local storage usage

🎯 Game Objective

  • Jump over incoming obstacles
  • Survive for as long as possible
  • Increase your score over time
  • Try to beat your previous high score

The longer you survive, the higher your score becomes.

🕹️ How to Play

  • Select your character before starting
  • Click Start Game
  • Press Space or any key to jump
  • Avoid obstacles coming from the right
  • If you hit an obstacle, the game ends

🏆 High Score System

The game uses localStorage to save your best score. It remains saved even after refreshing or closing the page.

  • Score is saved automatically
  • Only updated when you beat your record

🐾 Character Selection

  • Multiple characters available
  • Each character is visually different
  • Gameplay remains the same

💡 Technical Features

  • Dynamic DOM updates
  • Collision detection
  • Game loop using setInterval
  • Keyboard event handling
  • State management
  • localStorage usage

🚀 Future Improvements

  • Sound effects
  • Animated background
  • Coin system
  • Mobile controls
  • Online leaderboard

🎮 Summary

This game demonstrates how HTML, CSS, and JavaScript can be used to build interactive applications and introduces core game development logic in a beginner-friendly way.
