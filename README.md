# first_full_game
This is a browser-based 2D endless runner game built using HTML, CSS, and JavaScript.
The main goal of the game is to survive as long as possible by jumping over obstacles and achieving the highest score.

The game is designed with a simple structure but demonstrates key programming concepts such as:

DOM manipulation
Event handling (keyboard input)
Collision detection
Game loop logic
Local storage usage
🎯 Game Objective

The player controls a character (avatar) and must:

Jump over incoming obstacles
Survive for as long as possible
Increase their score over time
Try to beat the previous high score

The longer you survive, the higher your score becomes.

🕹️ How to Play
First, select your character (avatar) from the selection screen.
Click Start Game to begin.
Use the keyboard (Space or any key) to make your character jump.
Avoid obstacles that appear from the right side of the screen.
If you hit an obstacle, the game ends.
🏆 High Score System

The game includes a persistent high score system using localStorage.

Your best score is automatically saved in the browser.
The data remains saved even after refreshing or closing the page.
High score is only updated when you beat your previous record.

This ensures fair tracking of player progress.

🐾 Character Selection

Before starting the game, the player can choose between multiple characters (animals/avatars).

Each character is visually different
The selected character is used throughout the game
Some characters may repeat, but gameplay remains the same
💡 Technical Features

This project demonstrates the following core web development skills:

Dynamic DOM updates (score, movement, UI changes)
Collision detection using element coordinates
Game loop using setInterval
Keyboard event handling
State management (game over, jumping, score tracking)
Browser storage using localStorage
